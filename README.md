# SonicFabric

SonicFabric is a multi-target guitar audio processor architecture intended for bare metal, RTOS, and desktop versions.

## Documentation

The project documentation is organized under [docs/](docs/README.md):

- [docs/requirements/](docs/requirements/): product requirements and use cases.
- [docs/architecture/](docs/architecture/): architecture principles, views, contracts, and quality attribute scenarios.
- [docs/process/](docs/process/): development guide and project checklist.
- [docs/Terminology.md](docs/Terminology.md): shared vocabulary.

Root files are kept for repository-level entry points such as this README, [AGENTS.md](AGENTS.md), and the license.
