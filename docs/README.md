# Documentation

## Purpose

This folder contains the SonicFabric project documentation. The structure separates product intent, architecture design, and development process so each document has a clear owner.

## Folder Structure

- [requirements/](requirements/): product requirements and use cases.
- [architecture/](architecture/): architecture principles, views, interface contracts, and quality attribute scenarios.
- [process/](process/): project development guide and living checklist.
- [Terminology.md](Terminology.md): shared vocabulary used across all documentation.

## Current Entry Points

- [requirements/ProductAndSoftwareRequirements.md](requirements/ProductAndSoftwareRequirements.md): base product, hardware/runtime, and software quality requirements.
- [requirements/UseCases.md](requirements/UseCases.md): target-neutral user workflows.
- [architecture/ArchitectureAndDesignPrinciples.md](architecture/ArchitectureAndDesignPrinciples.md): architecture direction and open topics.
- [architecture/ArchitectureViews.md](architecture/ArchitectureViews.md): behavior and runtime diagrams.
- [architecture/StructuralArchitectureViews.md](architecture/StructuralArchitectureViews.md): static component, layer, dependency, and port boundary diagrams.
- [architecture/InterfaceContract.md](architecture/InterfaceContract.md): behavior-level interface contracts.
- [architecture/QualityAttributeScenarios.md](architecture/QualityAttributeScenarios.md): architecture-driving quality attribute scenarios.
- [process/ProjectDevelopmentGuide.md](process/ProjectDevelopmentGuide.md): step-by-step project procedure.
- [process/ProjectChecklist.md](process/ProjectChecklist.md): completed work and next steps.
